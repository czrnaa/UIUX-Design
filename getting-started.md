# Setting Up
Before diving into UI/UX design, you'll need to set up Figma and familiarize yourself with its workspace.

### 1. Create a Figma Account
1. Visit **https://www.figma.com/**
2. Click **Get started** or **Sign up**.
3. Create an account using:
   - Google
   - GitHub
   - Email
4. Verify your email if prompted.

### 2. Choose How to Use Figma
Figma can be used in two ways:
- **Browser Version** *(Recommended for beginners)*
  - No installation required.
  - Accessible from any modern web browser.

- **Desktop Application**
  - Download from **https://www.figma.com/downloads/**
  - Available for Windows and macOS.
  - Recommended for better performance and keyboard shortcuts.


### 3. Create Your First Design File
1. Log in to Figma.
2. From the dashboard, click **New Design File**.
3. Rename the file (e.g., **UIUX-Practice**).


### 4. Familiarize Yourself with the Workspace
Take a moment to identify these main areas:
- **Toolbar** – Tools for moving, drawing, creating frames, inserting text, and more.
- **Layers Panel** – Displays all objects and their hierarchy.
- **Assets Panel** – Access reusable components and libraries.
- **Canvas** – Your workspace where designs are created.
- **Properties Panel** – Modify the selected object's properties such as size, color, spacing, and constraints.

### 5. Enable Auto Save
Figma automatically saves your work to the cloud.
You'll notice the status indicator at the top of the window showing messages like:
- **Saving...**
- **Saved**
- **All changes saved**

No manual saving is required.

### 6. Recommended Folder Structure
As you progress, organize your files consistently:

```text
UIUX-Practice/
├── 01 - Fundamentals
├── 02 - Components
├── 03 - Auto Layout
├── 04 - Design Challenges
└── 05 - Portfolio Projects
```

### 7. Before You Continue
Make sure you can:
- Open Figma successfully
- Create a new design file
- Rename your file
- Navigate around the canvas (Zoom and Pan)
- Locate the Toolbar, Layers, Assets, and Properties panels
- Create and delete a simple shape

Once you're comfortable with the workspace, you're ready to begin learning the core building blocks of Figma, starting with **Frames**.
