# Exercise 1
1. Open Spotify.
2. Measure:
    - Title size
    - Subtitle size
    - Body text
3. Write them down.

## How to Measure
#### Option 1 (Recommended): Recreate in Figma
1. Take a screenshot of the Spotify screen.
2. Drag the screenshot into Figma.
3. Press **T** to create a text layer.
4. Match the font size until it closely aligns with the screenshot.
5. Record the size you used.

#### Option 2: Browser Inspection (Spotify Web)

1. Open **https://open.spotify.com**.
2. Right-click the text you want to inspect.
3. Select **Inspect**.
4. In the **Styles** or **Computed** panel, look for:
   - `font-size`
   - `font-weight`
   - `line-height`

> Note: Choose **Option 2** if you're familiar with HTML/CSS
