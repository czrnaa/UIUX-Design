# Practical Exercise

Instead of copying another app, use your own thesis Imagine you're redesigning your a **Management System.**

Go through each step:

## Research

- Who are the users?
- What tasks do they perform?

## Personas
- Student
- Adviser
- Administrator

## Information Architecture (Sample only)

```
Dashboard
├── Documents
├── Adviser
├── Notifications
├── Settings
```

## User Flow (Sample only)

```
Login
↓
Dashboard
↓
Upload Manuscript
↓
Confirmation
```

## Wireframe

Sketch the upload page using rectangles and text.

## Usability Test

Ask a friend:

`"Upload your file."`

Watch without helping.

## Notes

Don't learn UX as seven separate files.

Learn it as one continuous story:

```
A user has a problem 
→ you research it 
→ understand the user 
→ organize the information 
→ design the path they take 
→ sketch the solution 
→ test whether it actually works.
```

If you remember that story, every future project—including your own thesis, internship portfolio, and UI case studies—will have a solid UX foundation instead of just attractive screens.
