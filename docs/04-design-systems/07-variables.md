# Variables

Tokens are the **concept**. Figma Variables are one way of implementing that concept.

## Create a collection

```
Try:

blue-600
gray-50
gray-200
gray-600
gray-900

And number variables:

space-1 = 4
space-2 = 8
space-3 = 12
space-4 = 16
space-6 = 24
space-8 = 32
```

Then, if your available Figma plan/features allow the setup you want, experiment with semantic aliases such as:

```
color-action-primary → blue-600
color-text-primary → gray-900
```

Don't spend hours creating hundreds of variables. Five colors + six spacing values are enough to understand the system.
