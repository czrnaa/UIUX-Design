# What Actually Is a Design System?

A design system isn't a Figma file.

It's also not *"Here's our colors and buttons."*

Think of it as the shared language of a product.

Imagine developers and designers agree that:

```
Primary Button

Purpose: Main action
Height: 40px 
Horizontal padding: 16px
Radius: 8px
Background: color.action.primary
Text: label.medium
```

Now everyone speaks the same language.

Designer says: *"Use Primary Button."*

Developer knows what that means. Another designer knows what that means. Technical writer can document what that means. QA knows how it should behave.

That's the system.
