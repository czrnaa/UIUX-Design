# Components

A component in Figma is a **reusable design element** that you create once and reuse throughout your design.


## Open Figma and create a draft named **Design Systems Lab**.

With Pages:

```
00 Cover
01 Foundations
02 Components
03 Patterns
04 Templates
05 Documentation
99 Playground
```

Then go to Playground.

---

### Build a button

1. Don't draw a rectangle and put text over it.

    Create text: `Continue`

    Select it.

2. Press: `Shift + A`

    You now have *Auto Layout*.

3. Set approximately:
    |Layout|Value|
    |------|-----|
    |Horizontal padding|16|
    |Vertical padding|10|
    |Gap|8|
    |Radius|8|

4. Apply a background.

    Now change: `Continue` -> `Create an Account`

    The button should grow automatically.

    That's component thinking: *"Content influences the component rather than you manually drawing around content.*"

5. Now turn it into a **component**.
