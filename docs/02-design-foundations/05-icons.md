# Icons
### Icons communicate actions quickly.

Examples:
- ❤️ Favorite
- 🔍 Search
- 🏠 Home
- ⚙ Settings

## Don't Mix Icon Packs
|Bad|Good|
|---|----|
|Material, Heroicons, Lucide, Feather|One icon library|

## Recommendations
- Lucide
- Heroicons
- Material Symbols
- Phosphor

## Rules
Same stroke.

Same size.

Same style.
