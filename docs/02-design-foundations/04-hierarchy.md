# Visual Hierarchy
### Visual hierarchy controls where users look first.
Imagine this:
```
WELCOME BACK
Continue Listening
Recently Played
Liked Songs
```
Your eyes naturally go:

1

2

3

4

That's hierarchy.

## Five Ways to Create Hierarchy
1. **Size**: Big -> Small
2. **Weight**: Bold -> Regular
3. **Color**: Bright -> Muted
4. **Position**: Top -> Bottom
5. **White Space**: More breathing room -> More importance
