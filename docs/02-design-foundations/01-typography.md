# Typography
It is how text communicates importance, structure, and emotion.

Most beginners think typography is just choosing a font. Professional designers think:
> "***How can I help users scan information in under 3 seconds?***"

## Four Properties You Need to Know
1. **Font Family**

Usually, designers only use up to 2-3 fonts. And the recommended fonts for UI are:
- Inter
- SF Pro (Apple)
- Roboto (Google)
- Geist
- Poppins

2. **Font Size**

A common type scale are the following:
|Purpose|Size|
|-------|----|
Display|48px
H1|32px
H2|24px
H3|20px
Body|16px
Small|14px
Caption|12px
> Note: The body text is almost always 16px.

3. **Font Weight**

In this aspect, weights create 'hierarchy'. Imagine this:

|Weight|Text|
|---|---------|
|700|Dashboard|
|600|Analytics|
|400|Monthly report|
|400|Last updated yesterday|

Don't make everything bold. If everything is important... Nothing is.

4. **Line Height**

This is the vertical spacing between lines of text. 
> Tip. Avoid using the same value for the font size and line height (e.g., **16px / 16px**) for body text. Increasing the line height to around **24px** creates a much more readable experience.
