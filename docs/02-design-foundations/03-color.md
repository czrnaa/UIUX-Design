# Color & Contrast
Professionals don't pick colors because they *"look nice."* Every color has a purpose.

## UI Colors
- Primary - Used for:
  - Main buttons
  - Links
  - Brand
- Secondary
  - Less emphasis.
- Surface - Cards.
- Background - The page itself.
- Error - Red.
- Success - Green.
- Warning - Orange.

## Contrast
|Bad|Good|
|---|----|
|Gray text|Dark text|
|Gray background|Light background|
|***Impossible to read.***|***Easy to read.***|

> Note: Accessibility recommends sufficient contrast so text remains readable.
