# Design Foundations
This module introduces the core visual design principles used in UI design. These concepts help create interfaces that are readable, consistent, and user-friendly.

## Learning Objectives
By the end of this module, I should be able to:
- Apply typography effectively
- Use consistent spacing
- Create clear visual hierarchy
- Select appropriate icons
- Build accessible interfaces
- Use color intentionally
- Understand core design principles

## Topics
- Typography
- Spacing
- Visual Hierarchy
- Icons 
- Color
- Accessibility
- Design Principles

## Mini Project
Recreate Spotify Home Screen while applying:
- Proper typography
- Consistent spacing
- Clear hierarchy
- Appropriate icons
