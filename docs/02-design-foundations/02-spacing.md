# Spacing System
A **spacing system** is a set of consistent spacing values used throughout a design to create balanced layouts and improve visual organization. 

Instead of placing elements with random distances (e.g., 13px, 21px, or 37px), designers follow a predefined scale such as **4px, 8px, 12px, 16px, 24px, 32px**, and so on.

### Why Use a Spacing System?
- Creates consistency throughout the interface.
- Improves readability and visual hierarchy.
- Makes designs feel clean and organized.
- Simplifies collaboration with other designers and developers.
- Makes layouts easier to maintain and update.

## The 8-Point Grid
Where everything uses multiples of 8 mainly due to consistency.

Such as: `8, 16, 24, 32, 40, 48, 56, 64`

## Three Types of Spacing
1. `Padding` - which is the space inside.
```
Button

[ Text ]

Padding
```
2. `Margin` - space outside.
```
Button
↓
Margin
↓
Card
```
3. `Gap` - is the Auto Layout spacing.
```
Title

16 px space

Subtitle

16 px space

Button
```

## Unspoken Rule
Related things stay close. Unrelated things stay farther apart.
