# Accessibility

### Accessibility means everyone can use your design.
Including people with:
- Low vision
- Color blindness
- Motor impairments

## Some Rules to Remember
1. **Don't use color alone**
    |Bad|Good|
    |---|----|
    |Red = Error|Red text, Error icon, Message|
2. **Touch Targets**: Buttons should be at least: 44×44 px
3. **Readable Text**
    - 11px = Tiny.
    - Instead: 16px body text.
4. **Contrast**
    - Light background or
    - Light text and Dark background
5. **Icons Need Labels**
    - Sometimes don't assume everyone understands symbols.
