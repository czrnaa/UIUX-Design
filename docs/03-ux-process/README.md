# UX Process

This module introduces the User Experience (UX) design process used to create products that solve real user problems.

Unlike UI Design, which focuses on visual appearance, UX Design focuses on understanding users, defining problems, and designing effective solutions.


## Learning Objectives

By the end of this module, I should be able to:

- Understand the Design Thinking process
- Conduct basic user research
- Create user personas
- Organize information logically
- Design user flows
- Build wireframes
- Perform usability testing


## UX Workflow

```
Empathize
↓
Define
↓
Ideate
↓
Prototype
↓
Test
```
