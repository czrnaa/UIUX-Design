# Usability Testing

The easiest way to find problems is to watch users.

***Don't explain. Observe.***

## Ponder on Questions

- Where did they hesitate?
- Where did they click?
- Did they finish?
- How long?

## Evaluate Using Metrics

- Task Success
- Completion Time
- Error Rate
- Satisfaction

### Quick Exercise

Ask a friend to use your wireframe. Take notes.
