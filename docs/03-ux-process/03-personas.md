# Personas
Personas represent typical users.

### Example
```
Maria
Age: 20
College Student
Goal: Submit thesis documents quickly.
Pain Point: Portal navigation is confusing.
Needs:
- Simple dashboard
- Search
- Notifications
```

## Good personas contain...
- Goals
- Behaviors
- Motivations
- Frustrations

*Not just age.*
