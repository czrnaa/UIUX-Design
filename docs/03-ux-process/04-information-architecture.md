# Information Architecture

Information Architecture (IA) organizes content so users can find information easily. Think of it as the blueprint of your app.

### Example
```
Dashboard
├── Profile
├── Courses
├── Grades
├── Settings
```

|Bad IA|Good IA|
|------|-------|
|Everything everywhere|Logical organization|

## Some Methods to Consider
- Card Sorting
- Site Maps
- Navigation Structure
