# What is Design Thinking?

Design Thinking is a human-centered approach to solving problems.

Instead of asking
> *"How do I build this?"*

UX designers ask
> *"Should this even exist?"*

## The Five Stages
1. **Empathize** - Understand users.
    
    Examples
    - Interviews
    - Observation
    - Surveys
    
    > Goal: Understand people.
2. **Define** - Identify the actual problem.

    - Bad: "Students need a better app."
    - Good: "Students cannot easily find thesis documents because search is confusing."
3. **Ideate** - Generate many ideas.
    - No judging.
    - Brainstorm.
4. **Prototype** - Create quick solutions.
    - Low fidelity.
    - High fidelity.
    - Interactive.
5. **Test** - Watch people use it.
    - Observe.
    - Improve.
    - Repeat.
