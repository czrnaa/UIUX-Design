# Layers
Everything in Figma is a **layer**.
- Text? Layer.
- Rectangle? Layer.
- Circle? Layer.
- Image? Layer.
- Button? Actually multiple layers.

## Example
```
Button
Rectangle
Text
```
The button isn't one thing. ***It's two layers.***

## Layers can be
- Grouped
- Nested
- Hidden
- Locked
- Renamed

### Good designers NEVER leave this:
```
Rectangle 34
Rectangle 52
Frame 4
Group 7
```
### Instead
```
Login Button
Logo
Header
Navigation
Footer
```
