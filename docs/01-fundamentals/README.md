# Figma Fundamentals

This module covers the essential concepts required to start designing in Figma. It introduces the workspace, how designs are organized, and the tools used to build scalable user interfaces.

## Learning Objectives

By the end of this module, learner should be able to:
- Navigate the Figma interface confidently
- Understand how Frames organize designs
- Manage Layers efficiently
- Organize projects using Pages
- Create reusable Components
- Build responsive layouts using Auto Layout
- Increase productivity using keyboard shortcuts


## Topics
1. `frames` - Learn how to create, organize, and use frames as the foundation for screens, layouts, and responsive designs.
2. `pages` - Understand how to organize your Figma files into multiple pages for better project structure and workflow.
3. `layers`- Explore how layers work, including arranging, grouping, locking, hiding, and managing design elements efficiently.
4. `components` - Learn to build reusable UI elements, create component variants, and manage instances for scalable designs.
5. `auto-layout` - Master responsive layouts by automatically arranging, resizing, spacing, and aligning elements with Auto Layout.
6. `shortcuts` - Improve your workflow with essential Figma keyboard shortcuts for navigation, editing, selection, and design efficiency.
