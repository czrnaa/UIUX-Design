# Auto Layout
Without Auto Layout, spacing becomes impossible.

Imagine
```
Login
Email
Password
Button
```
Now imagine adding `Forgot Password?` button link.

*Everything breaks.* 

Auto Layout fixes this. Think of it like stacking LEGO.
```
↓
Logo
↓
Email
↓
Password
↓
Button
```
Everything automatically moves.

---
### Shortcut
`Shift + A`
