# Frames
Frames are probably the MOST IMPORTANT thing in Figma.

A lot of beginners think:
> Frame = Rectangle

Wrong.

A frame is more like an artboard. Imagine you're designing an iPhone. The phone screen is a **Frame**.

### Inside it are:
- Buttons
- Text
- Icons
- Images
- Everything.

---

### Example
```
Phone Frame
-------------------
Logo

Email Field

Password Field

Button
-------------------
```
---
